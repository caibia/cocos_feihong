## 六、数据访问抽象（为未来联网预留接口）

本地与联网的差异只在 **数据来源**（本地 json vs 网络协议）与 **延迟语义**（同步 vs 异步）。所有 View 与业务层不直接读 json、不直接发协议，全部通过下面这套接口访问；切到联网时只新增 `Remote*Repo` 实现并在工厂里替换，View 与 DB 层无需改动。

### 6.1 接口定义（统一异步、统一事件）

放在 `assets/script/app/module/Login/Repo/`：

```ts
// IServerListRepo.ts —— 服务器列表数据源接口
export interface IServerInfo {
    id: number;
    groupId: string;
    name: string;
    state: 0 | 1 | 2 | 3;          // 流暢 / 火熱 / 爆滿 / 維護
    openTime: number;               // 0=已开服，>0=未来时间戳
    playerName?: string;            // 我玩过的服才有
    level?: number;
    iconId?: number;
}

export interface IServerGroup {
    id: string;
    name: string;
    isRecommend: boolean;
    range: [number, number];
}

export interface IServerListSnapshot {
    groups: IServerGroup[];
    servers: IServerInfo[];
    myServerIds: number[];
}

export interface IServerListRepo {
    /** 拉取全部服务器列表（含分组与我的服）。本地实现读 json，远端实现走 http/socket */
    fetchServerList(): Promise<IServerListSnapshot>;
    /** 取上次登录服 id，无则返回 0 */
    fetchLastLoginServerId(): Promise<number>;
    /** 写上次登录服 id（本地：写存档；远端：调接口） */
    saveLastLoginServerId(serverId: number): Promise<void>;
}

// IUserAccountRepo.ts —— 账号/登录接口
export interface ILoginResult {
    ok: boolean;
    code: number;
    token?: string;
}

export interface IUserAccountRepo {
    /** 进入游戏前的"登录"动作：本地实现写存档即可；远端实现发 C2S_LOGIN 等响应 */
    login(account: string, serverId: number): Promise<ILoginResult>;
    /** 读上次登录账号 */
    fetchLastAccount(): Promise<string>;
}
```

### 6.2 工厂与切换点

`assets/script/app/module/Login/Repo/RepoFactory.ts`：

```ts
import { IServerListRepo } from "./IServerListRepo";
import { IUserAccountRepo } from "./IUserAccountRepo";
import LocalServerListRepo from "./LocalServerListRepo";
import LocalUserAccountRepo from "./LocalUserAccountRepo";

const MODE: "local" | "remote" = "local";   // 切到联网时改这一行

export default class RepoFactory {
    private static _serverRepo: IServerListRepo;
    private static _userRepo: IUserAccountRepo;

    public static getServerListRepo(): IServerListRepo {
        if (!this._serverRepo) {
            this._serverRepo = MODE === "local" ? new LocalServerListRepo() : /* new RemoteServerListRepo() */ new LocalServerListRepo();
        }
        return this._serverRepo;
    }

    public static getUserAccountRepo(): IUserAccountRepo {
        if (!this._userRepo) {
            this._userRepo = MODE === "local" ? new LocalUserAccountRepo() : /* new RemoteUserAccountRepo() */ new LocalUserAccountRepo();
        }
        return this._userRepo;
    }
}
```

> 联网时新增 `RemoteServerListRepo.ts` 与 `RemoteUserAccountRepo.ts`（走 `NetWorkMgr` / 协议），把 `MODE` 改为 `"remote"` 即可，**View / DB / FGUI 不动**。

### 6.3 本地实现

- `LocalServerListRepo.ts`：用 `cc.resources.load("config/json/serverlist", JsonAsset, ...)` 读 §4 的 json，转 `IServerListSnapshot` 返回；`saveLastLoginServerId` 走本地存档（同 `LoginStorage`）。所有方法用 `Promise.resolve(...)` 包裹，保留异步签名，方便未来切远端时不改调用方。
- `LocalUserAccountRepo.ts`：`login(account, serverId)` 写本地存档（最近账号、登录时间、服 id），`Promise.resolve({ ok:true, code:0 })`。

### 6.4 业务层只依赖接口

- `LoginServerDB.ts` 内部只持有 `IServerListRepo`，通过 `RepoFactory.getServerListRepo()` 拿；对外暴露同步访问 + 内部 `await fetchServerList()` 的缓存层。
- `UserDB.ts` 的 `localLogin()` 重命名为 `enterGame()`，内部调 `RepoFactory.getUserAccountRepo().login(...)`，调用方完全感知不到底层是本地还是远端。
- 加载完成 / 失败统一通过 `EventManager` 派发 `EVENT_SERVER_LIST_READY / EVENT_LOGIN_SUCCESS / EVENT_LOGIN_FAIL`，View 只监听事件，不与 Repo 直接耦合。

### 6.5 切到联网时的清单（未来）

只改这些，业务代码与 UI 都不动：
1. 新增 `RemoteServerListRepo.ts`（走 `NetWorkMgr.socketConnect` + `C2S_GET_SERVER_LIST` / `S2C_GET_SERVER_LIST`）。
2. 新增 `RemoteUserAccountRepo.ts`（走 `C2S_LOGIN / S2C_LOGIN`）。
3. `RepoFactory.MODE = "remote"`。
4. 协议号在 [assets/script/app/define/ProtoDefine.ts](assets/script/app/define/ProtoDefine.ts) 注册，IDL 在 `dts/IProto.d.ts` 补类型。
