# Spine 3.8 预览工具

浏览并预览 Spine 3.8.99 动画(json/skel + atlas + png)。基于官方 spine-webgl 3.8 运行时,
版本与数据对齐,运行时已内置,离线可用。文本(`.json`)与二进制(`.skel`)两种骨架格式均支持。

不自动扫描固定目录:启动后由你**手选目录或文件**,再扫描所选目录下的全部 spine。

## 启动

双击 `run.cmd` 即可(服务在独立窗口运行,稍候自动打开浏览器;关闭该窗口停止):

```bat
run.cmd            :: 默认端口 8970
run.cmd 9000       :: 指定端口
```

或直接用 python:

```powershell
python tools/spine-preview/serve.py          # 默认 http://127.0.0.1:8970/
python tools/spine-preview/serve.py --port 9000
```

## 选择来源

页面左上角三种方式任选其一:

- **选择目录…**:弹出原生窗口选一个文件夹,递归扫描其下全部 spine。
- **选择文件…**:弹出原生窗口选某个 `.json`/`.skel` 或 `.atlas`,直接加载该 spine。
- **粘贴路径**:在输入框填目录或文件的绝对路径,回车或点『加载』。

所选根会显示在按钮下方;`/assets` 仅托管该根目录内的文件。

## 功能

- **列表 / 搜索**:左侧按首层目录分组列出 spine,顶部搜索框按名称或路径过滤。
- **动画 / 皮肤**:下拉切换;循环、播放/暂停、速度(0.1×~2×)、时间轴拖动定位。
- **视图操作**:鼠标滚轮缩放、按住拖动平移、`适应`(按当前姿态包围盒框选)、`重置视图`。
- **背景**:深灰 / 黑 / 白 / 绿 / 品红 / 透明(棋盘格)。
- **预乘 Alpha**:贴图非预乘导致边缘发黑/发亮时取消勾选即可即时修正。
- **深链**:`?root=<路径>&open=<目录>/<名称>` 打开时自动加载并选中,便于书签/分享。

## 约束

- 一个 spine 条目 = 同一文件夹内**同名的 `.json`(或 `.skel`)+ `.atlas` 同时存在**。
  同名 `.json` 与 `.skel` 并存时优先用 `.json`(文本读取更宽容)。
- 缺少 atlas、atlas 未声明贴图页、或引用的 png 缺失等情况,**不静默跳过**:
  该条目在列表中标红并给出原因,加载失败时舞台上直接显示真实错误。
